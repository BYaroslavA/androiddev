# 🎨 Фотошоп 2.0 (Photoshop 2.0) — Android Photo Editor

Сучасний, швидкий та стильний фоторедактор для Android, створений у межах практичного завдання з розширеними можливостями обробки зображень.

Застосунок оптимізовано як для роботи на **фізичних смартфонах** (знімання фото на камеру), так і на **емуляторі Android Studio** (завантаження з галереї, пряме завантаження за URL з Інтернету або вбудоване художнє демо-зображення).

---

## ✨ Основні можливості

### 📸 1. Джерела зображень
* **Камера пристрою**: миттєве фотографування через системну камеру (`ActivityResultContracts.TakePicturePreview`).
* **Галерея / Локальні файли**: імпорт будь-яких картинок із пам'яті пристрою чи папки "Downloads" на емуляторі.
* **Завантаження з Інтернету**: діалог для вставки будь-якого прямого URL фотографії або вибір одного з 3 готових якісних зразків (Гори, Місто, Океан).
* **Вбудоване Демо-фото**: генерація красивого пейзажу (захід сонця, гори, озеро) без підключення до мережі та без дозволів.

---

### 🎨 2. Колекція з 12 художніх фільтрів (з прев'ю-мініатюрами)
1. **Оригінал** — початковий стан зображення.
2. **Ч/Б (Black & White)** — класична монохромна градація сірого.
3. **Сепія (Sepia)** — теплий ретро-ефект старовинної фотографії.
4. **Негатив (Invert)** — інверсія кольорових каналів.
5. **Вінтаж (Vintage)** — м'які плівкові відтінки 90-х.
6. **Теплий (Warm)** — золотисті сонячні тони.
7. **Холодний (Cool)** — свіжі синюваті ранкові відтінки.
8. **Кіберпанк (Cyberpunk)** — неонові рожево-блакитні контрасти.
9. **Драма (Drama)** — нуарний контраст із приглушеною насиченістю.
10. **Смарагд (Emerald)** — насичені смарагдово-зелені тони.
11. **Рубін (Ruby)** — глибокі рубіново-червоні акценти.
12. **Золотий (Golden Hour)** — тепле вечірнє сяйво.

---

### 🎛️ 3. Тонка корекція параметрів (з GPU живим прев'ю)
* **Яскравість (Brightness)**: від `-100` до `+100`.
* **Контрастність (Contrast)**: від `-100` до `+100`.
* **Насиченість (Saturation)**: від `-100` до `+100`.
> ⚡ *Швидкодія:* Регулювання повзунками використовує апаратне прискорення GPU через `ColorMatrixColorFilter`, забезпечуючи 60 FPS без лагів навіть для великих фото.

---

### 🔄 4. Геометрія та трансформація
* **Поворот вліво (-90°)** та **Поворот вправо (+90°)**.
* **Відзеркалення по горизонталі (Дзеркало Г)** — симетричний розворот зліва направо.
* **Відзеркалення по вертикалі (Дзеркало В)** — перевертання зверху вниз.

---

### ✂️ 5. Інтерактивна обрізка (Crop)
* Спеціальний кастомний `CropOverlayView` із затемненням фону, неоновою рамкою та кутовими маркерами.
* **Сітка правила третин** для професійної побудови композиції.
* **Популярні пропорції кадру**:
  * `Вільна` — довільне перетягування будь-якого кута чи сторони.
  * `1:1 Квадрат` — ідеально для постів Instagram / аватарів.
  * `4:3 Фото` — класичний формат фотокамер.
  * `16:9 Широкий` — формат екранів та YouTube.
  * `9:16 Сторіс` — Stories, Reels, TikTok.
  * `3:4 Портрет` — класичний вертикальний портрет.

---

### 🌘 6. Спеціальні ефекти
* **Віньєтка (Vignette)**: плавне радіальне затемнення країв від `0%` до `100%`, що фокусує погляд на центрі композиції.

---

### 🛠️ 7. Інструменти робочого процесу
* 👁️ **Порівняння з оригіналом (Compare)**: натисніть і утримуйте кнопку "Око" у верхній панелі, щоб побачити початкове фото без змін; відпустіть — повернеться відредагований результат.
* ↩️ **Багаторівневе скасування (Undo)** та **Повторення (Redo)**: зручний стек історії дій.
* 🔄 **Скидання (Reset)**: швидке повернення до оригіналу в один клік.
* 💾 **Збереження (Save)**: запис фінального фото високої якості до публічної галереї пристрою (`Pictures/Photoshop2.0`) через сучасний `MediaStore API`.
* 📤 **Поділитися (Share)**: відправка зображення в інші додатки (Telegram, Viber, Instagram тощо) через системний `Intent.ACTION_SEND` та `FileProvider`.

---

## 📱 Дизайн та інтерфейс ("Крутий вигляд")
* **Темна студійна тема (AMOLED Dark)**: глибокі темні тони (`#0D0F14`, `#161920`, `#20242D`), які не спотворюють сприйняття кольорів.
* **Неоновий акцент Cyan (`#00E5FF`)**: стильний контраст елементів керування та активних вкладок.
* **Edge-to-Edge**: повне використання площі екрана із врахуванням системних відступів (Status Bar та Navigation Bar).
* **Горизонтальна стрічка фільтрів**: живі мініатюри актуального зображення для кожного фільтра.

## 🚀 Технологічний стек
* **Мова**: Kotlin 100%
* **Архітектура та компоненти**:
  * Android Jetpack: `AppCompat`, `Activity-KTX`, `ConstraintLayout`, `Lifecycle Coroutine Scope`.
  * `ViewBinding` для безпечної та швидкої взаємодії з View.
  * Material Design 3 (Cards, Sliders, Chips, Buttons).
  * Графічний пайплайн: `android.graphics.Canvas`, `ColorMatrix`, `RadialGradient`, `Matrix`.
  * Корутини (`Dispatchers.IO`, `Dispatchers.Default`, `Dispatchers.Main`) для плавної фонової роботи без підвисань інтерфейсу.
  * `FileProvider` для безпечного обміну файлами між додатками.
* **Мінімальна версія Android**: Android 13 (API 33+)
* **Цільова версія Android**: Android 15/16 (API 37)

## 🛠️ Як зібрати та запустити проєкт
1. Відкрийте проєкт в **Android Studio**.
2. Зачекайте завершення Gradle Sync.
3. Запустіть на емуляторі або підключеному телефоні натисканням **Run (Shift + F10)** або виконайте в терміналі:
   ```bash
   ./gradlew installDebug
   ```
4. Для запуску тестів:
   ```bash
   ./gradlew testDebugUnitTest
   ```
