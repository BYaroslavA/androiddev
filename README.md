# 🎨 Lumen Studio — Мобильный фоторедактор

**Lumen Studio** — современный мобильный фоторедактор в стиле Adobe Photoshop, реализованный исключительно на **Jetpack Compose** и **Material 3** без использования XML-разметки.

---

## 🌟 Основные возможности

### 1. 🖼️ Превью и Canvas-арт
- **Процедурная графика на Canvas:** Изображение заката в горах с силуэтом путешественника отрисовано вручную векторными примитивами и градиентами без внешних картинок.
- **Интерактивное масштабирование (Zoom):** Плавное приближение и отдаление от **50% до 200%** через `Modifier.graphicsLayer` с анимацией `animateFloatAsState`.
- **Быстрое сравнение с оригиналом:** Нажатие и удержание пальцем/мышью на изображении показывает снимок **до обработки** (с бейджем *«ОРИГИНАЛ»*), отпускание возвращает применённые эффекты.
- **Информационные чипы:** Отображение текущего масштаба и разрешения фото (`1080x1350`).

### 2. 🎛️ Аппаратная цветокоррекция (ColorMatrix)
Реальное преобразование пикселей на GPU через 4x5 матрицу трансформации цветов:
- **Яркость (Brightness):** от `-100%` до `+100%`.
- **Контраст (Contrast):** от `0%` до `200%` (норма: `100%`).
- **Насыщенность (Saturation):** от `0%` (ч/б) до `200%`.
- **Температура (Temperature):** тёплые (amber) и холодные (blue) тона.
- **Кнопка «Сбросить»:** Мгновенный возврат всех ползунков к базовым значениям.

### 3. 🪄 Предустановленные фильтры
Панель пресетов с живыми миниатюрами:
- **Original** — исходное изображение
- **Vivid** — повышенный контраст и сочные цвета
- **Mono** — кинематографичный чёрно-белый
- **Warm** — тёплый закатный золотой час
- **Cold** — сумеречные синие оттенки
- **Vintage** — тёплый ретро-сепия эффект

### 4. 🛠️ Панель инструментов
Горизонтальный `LazyRow` с плавной spring-анимацией выбранного инструмента:
- **Фильтры:** Выбор пресетов с реальным предпросмотром на миниатюрах.
- **Кисть:** Настройка размера (1–100 px), прозрачности (0–100%) и палитра из 5 цветов.
- **Текст:** Ввод текста в реальном времени, настройка размера шрифта и цвета с отрисовкой теней.
- **Стикеры:** Выбор векторных стикеров и штампов (☀️, ⛰️, 🦅, ✨, 🌙, 🌸).
- **Обрезка (Кадрирование):** Переключение соотношений сторон (`Оригинал`, `1:1`, `4:5`, `16:9`, `9:16`).
- **Рамки:** Стилизация границ (`Нет`, `Тонкая`, `Полароид`, `Неон`, `Золото`).
- **Ластик:** Регулировка размера ластика.

### 5. 📑 Панель слоёв (Layers BottomSheet)
Полноценная система слоёв в стиле десктопных графических редакторов:
- **Слои:** *Фон*, *Портрет*, *Текст Sunset*, *Стикер*, *Фильтр*.
- **Видимость:** Включение / выключение каждого слоя (иконка глаза).
- **Непрозрачность:** Индивидуальный ползунок прозрачности для каждого слоя (0–100%).
- **Порядок слоёв:** Перемещение слоёв выше/ниже кнопками стрелок (изменяет порядок отрисовки).
- **Удаление:** Возможность удалить ненужный слой.

### 6. ↩️ Undo / Redo и экспорт
- **История изменений:** Полноценный стек Undo / Redo для слайдеров, фильтров и манипуляций со слоями.
- **Экспорт:** Кнопка «Экспорт» с уведомлением через Material 3 `SnackbarHost`.
- **Шеринг:** Быстрое копирование ссылки/проекта.

## 🏗️ Архитектура и структура проекта

Архитектура построена на паттерне **MVVM + UDF (Unidirectional Data Flow)**:
- UI не хранит бизнес-логику и только рендерит состояние `EditorUiState`.
- Все действия и вычисления матриц инкапсулированы в `EditorViewModel` и `FakeData`.
- Все основные компоненты снабжены `@Preview` и вынесены в отдельные файлы.

```
app/src/main/java/com/example/myapplication/
│
├── MainActivity.kt           # Единственная Activity: setContent { LumenApp() }
│
└── ui/
    ├── EditorScreen.kt       # Главный экран, Canvas превью, жесты удержания, зум
    ├── TopBar.kt             # Верхняя панель: Undo/Redo, инфо о файле, Экспорт
    ├── ToolsPanel.kt         # Панель инструментов (LazyRow) + анимированные подпанели
    ├── AdjustPanel.kt        # Слайдеры цветокоррекции ColorMatrix и кнопка сброса
    ├── LayersPanel.kt        # BottomSheet управления слоями и порядком отрисовки
    ├── EditorViewModel.kt    # Управление состоянием экрана, стеки Undo/Redo
    ├── FakeData.kt           # Модели слоёв, матричная математика 4x5, пресеты
    │
    └── theme/
        ├── Color.kt          # Тёмная палитра (#121212, #1E1E1E, #252525, акценты #7C4DFF, #00E5FF)
        └── Theme.kt          # LumenStudioTheme (Material 3 DarkColorScheme)
```

## 💻 Технологический стек

- **Язык:** Kotlin 2.4+
- **UI фреймворк:** Jetpack Compose (BOM 2024.12.01)
- **Дизайн-система:** Material Design 3 (`androidx.compose.material3:material3`)
- **Иконки:** Material Icons Extended
- **Архитектура:** AndroidX Lifecycle ViewModel Compose, StateFlow
- **Сборка:** Android Gradle Plugin (AGP) 9.5+, Gradle 9+
- **SDK:** `minSdk = 33`, `targetSdk = 37`, `compileSdk = 37`

## 🚀 Запуск и сборка

### В среде Android Studio
1. В выпадающем списке конфигураций запуска в верхней панели выберите **`app`** (не *Tests*).
2. Выберите эмулятор (например, *Pixel 10 Pro XL*) или физическое устройство.
3. Нажмите кнопку **Run ▶** (`Shift + F10`).

### Просмотр через Compose Preview (без эмулятора)
1. Откройте любой из UI-файлов (например, [`EditorScreen.kt`](file:///C:/Users/bortn/AndroidStudioProjects/MyApplication3/app/src/main/java/com/example/myapplication/ui/EditorScreen.kt) или [`AdjustPanel.kt`](file:///C:/Users/bortn/AndroidStudioProjects/MyApplication3/app/src/main/java/com/example/myapplication/ui/AdjustPanel.kt)).
2. В верхнем правом углу вкладки редактора переключитесь в режим **Split** или **Design**.

### Сборка через Gradle CLI
```bash
# Сборка debug APK
./gradlew assembleDebug

# Установка на подключенное устройство
./gradlew installDebug
```
